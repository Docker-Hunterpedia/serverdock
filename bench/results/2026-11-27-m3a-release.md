**This file is a summary of local runs, not the CI gate.** The CI "S2 live watcher" number is the release gate: **PENDING**, recorded when the bench job runs on the ready pull request (it does not run on a draft). Full details and reading notes: [docs/research/05-phase0-measurements.md](../../docs/research/05-phase0-measurements.md#m3a-release-measurements-step-15).

- Environment: a cloud container, amd64, every scenario in a `--memory 1g --cpus 1` container, 3 runs each, median of the per-run medians. Not a 1 GB VPS.
- Images: S2 and S4 built from commit `92186ad`; S5 to S9 from `197c847`. The bind-isolation fix `d5f0327` came after, so these numbers do not include it.
- Caveat: temporary vendor and cgroup shims were used to run locally; they were never committed.
- Scenarios 5 to 9 run locally only, with host networking and `--allow-loopback-registry`.
