# 0002 — Go for control plane, agent and CLI

**Status:** accepted by the maintainer · **Date:** 2026-11-20

**Context.** Footprint is the core promise. Rust saves ~5–10 MB per process; Go has embeddable compose-go, BuildKit, Railpack, Caddy/certmagic, and the Anthropic Go SDK. See [research/03](../research/03-architecture-options.md#1-language-go-vs-rust--go).

**Decision.** Go, `CGO_ENABLED=0`, pure-Go SQLite driver, `GOMEMLIMIT` set.

**Consequences.** Easy cross-compile and contributions; must actively guard against GC/heap growth (footprint agent + CI bench).
